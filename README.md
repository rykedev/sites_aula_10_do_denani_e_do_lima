# 📱 TechNews Today - Portal de Tecnologia

O **TechNews Today** é uma página web moderna e responsiva focada na publicação de notícias e novidades do mundo da tecnologia. O projeto apresenta um design escuro (*dark mode*), com efeitos visuais avançados como *glassmorphism*, gradientes e uma interface interativa para a leitura de conteúdos e subscrição de *newsletters*.

---

## 🚀 Funcionalidades

- **Cabeçalho Fixo com Glassmorphism:** Navegação com efeito de vidro fosco (*blur*) e gradientes atrativos.
- **Artigos Interativos:** Notícias em destaque com suporte ao elemento HTML `<details>` para expansão de conteúdo ("Leia mais").
- **Integração de Vídeo:** Secção dedicada para a incorporação de vídeos do YouTube.
- **Formulário de Newsletter:** Área interativa para captação de emails com seleção de tópicos de interesse e aceitação de termos.
- **Design Responsivo:** Layout adaptável para dispositivos móveis e computadores através de *CSS Grid* e *Media Queries*.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página (`<header>`, `<main>`, `<article>`, `<section>`, `<footer_>`, etc.).
- **CSS3:** 
  - Estilização moderna com variados gradientes e cantos arredondados.
  - *Layout* responsivo usando **CSS Grid** e **Flexbox**.
  - Efeitos de transição (`hover`) e suporte a *backdrop-filter*.
